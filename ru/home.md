# Скрипты PoEBane

Скрипты PoEBane — это **TypeScript / JavaScript**, которые выполняются на **живом** процессе
*Path of Exile 2*. Скрипт читает состояние игры через глобальный объект `World`, управляет вводом и
может включать встроенные автоматизации — всё это в несколько строк в редакторе Studio.

## Модель в одном абзаце

Вы **читаете** живое состояние из `World` (`Player`, `Entities`, `Flasks`, `Inventory`, `Area`,
`Camera`, `Party`, `Ui`, `Stash`, `ItemsOnGround`, `Osd`) — всегда после `PlayerValid()`. Вы
**действуете** через `PressKey` / `HoldKey` / `ReleaseKey`, используете слоты пояса через
`World.Flasks.Use(i)` и проецируете мир на экран через `World.W2S`. Высокоуровневая автоматизация
включается через `SetAutoStash` / `SetAutoFarm` / `SetAutoFollow` / `SetAutoPickup`. Текст на оверлее
рисуется через `DisplayText`, логирование — через `Log` / `Info` / `Warn` / `Error`.

## Актуальный API

Точные сигнатуры находятся в сгенерированном `poebane.d.ts`, **а не** в этой вики — рабочая сборка
выпускает собственную копию, поэтому она никогда не расходится с кодом. Если члена нет в
`poebane.d.ts`, значит его не существует; не полагайтесь на него. Эти страницы описывают концепции и
примеры; `.d.ts` — источник истины для точных имён и типов.
