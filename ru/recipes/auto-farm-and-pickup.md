# Рецепт — авто-фарм и подбор

Для зачистки и лута предпочитайте высокоуровневые переключатели ручному управлению перемещением.
Каждый — простой вкл/выкл, обрабатываемый внутри PoEBane, так что ваш скрипт остаётся крошечным.

```ts
SetAutoFarm(true);      // зачищать текущую область
SetAutoPickup(true);    // подбирать дроп
SetAutoStash(true);     // складывать в стэш, когда полно / у стэша
// SetAutoFollow(true); // следовать за лидером группы вместо фарма

Info("авто-фарм и подбор включены");
```

Когда что использовать:

- `SetAutoFarm` — убивать и зачищать текущую область.
- `SetAutoPickup` — подбирать предметы с земли (используйте вместе с фармом).
- `SetAutoStash` — выгружать инвентарь в стэш.
- `SetAutoFollow` — следовать вместо фарма (игра в группе). Не совмещайте с `SetAutoFarm`.

Вы включаете переключатели, а встроенная автоматизация делает остальное. Добавляйте свою логику на тик
(флаконы, оповещения) рядом — только держите её дешёвой, ведь она работает в игровом цикле.
