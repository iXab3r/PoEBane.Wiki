# PoEBane Wiki

Reference docs for writing **PoEBane** automation scripts for *Path of Exile 2*.

PoEBane scripts are TypeScript/JavaScript evaluated against the **live** game: you read
game state from `World`, drive input via `Input` / `PressKey` / the high-level `SetAuto*`
toggles, and (WIP) register reactive rules with `Group` / `OnTimer` / `OnHotkey`.

This repository is the single source of truth for the scripting surface. It is:

- **Mounted read-only into the in-app Codex session** — the Studio chat clones this repo to
  `{AppData}/ai/docs` and greps it with its own tools, so the assistant answers from the real
  API instead of from memory.
- **Exported as a portable guidance pack** for external agents (Claude Code, etc.).

## Authoritative API

`scripting/api/poebane.d.ts` is **generated from the runtime bindings** (`// @generated by
script bindgen`). Its `apiHash` matches the `POEBANE_SCRIPT_API_HASH` global exposed to every
script. **If a member is not in that file, it does not exist** — do not invent APIs.
