# PoEBane Wiki

Reference docs for writing **PoEBane** automation scripts for *Path of Exile 2*.

PoEBane scripts are TypeScript/JavaScript evaluated against the **live** game: you read
game state from `World`, drive input via `Input` / `PressKey` / the high-level `SetAuto*`
toggles, and (WIP) register reactive rules with `Group` / `OnTimer` / `OnHotkey`.

This repository is the **prose** source of truth for scripting — concepts, best-practices, and
examples. The exact, machine-generated API surface (`poebane.d.ts`) is **not committed here** on
purpose: it is derived from the build so it can never drift (see
[`scripting/api/README.md`](scripting/api/README.md)). The wiki is:

- **Mounted read-only into the in-app Codex session** — the Studio chat clones this repo to
  `{AppData}/ai/docs` and greps it, alongside a separate live mount of the running build's
  `poebane.d.ts`, so the assistant answers from the real, current API instead of from memory.
- **Exported as a portable guidance pack** for external agents (Claude Code, etc.).

## Authoritative API

The generated `poebane.d.ts` (`// @generated by script bindgen`) is authoritative. **If a member is
not in it, it does not exist** — do not invent APIs. It is not stored in this wiki; the running build
emits its own copy (mounted live in the app, or read from `src/PoeBane/ui/generated/poebane.d.ts` in
the build). Its `apiHash` equals the `POEBANE_SCRIPT_API_HASH` global, so a copy always self-declares
which build it came from.
